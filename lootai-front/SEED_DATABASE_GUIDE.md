# 🌱 Руководство по инициализации базы данных

## Проблема

При первом запуске приложения в Firebase Firestore отсутствуют данные, что приводит к ошибкам при загрузке задач и чатов.

## Решение

Используйте встроенные инструменты разработчика для добавления тестовых данных.

## Как использовать:

### 1. Откройте настройки

- Запустите приложение в режиме разработки
- Перейдите в раздел **"Настройки"** через нижнее меню
- Прокрутите вниз до секции **"🛠️ ИНСТРУМЕНТЫ РАЗРАБОТЧИКА"**

### 2. Настройте координаты

У вас есть два варианта:

#### Вариант A: Использовать свое местоположение

1. Нажмите кнопку **"📍 Использовать мое местоположение"**
2. Разрешите доступ к геолокации в браузере
3. Координаты автоматически заполнятся

#### Вариант B: Ввести координаты вручную

1. Введите широту (например: `55.7558` для Москвы)
2. Введите долготу (например: `37.6176` для Москвы)
3. Используйте координаты вашего города

### 3. Добавьте тестовые задачи

1. Нажмите кнопку **"🌱 Добавить тестовые задачи"**
2. Дождитесь завершения процесса
3. Проверьте сообщение об успешном добавлении

## Что будет добавлено:

### 📋 Тестовые задачи (6 штук):

- **Уборка парка** - общественная задача
- **Помощь с переездом** - пользовательская задача
- **Обучение программированию** - пользовательская задача
- **Благоустройство двора** - общественная задача
- **Квест: Поиск сокровищ** - квестовая задача
- **Волонтерство в приюте** - общественная задача

### 📍 Координаты:

- Все задачи будут размещены в радиусе **1 км** от указанных координат
- Каждая задача имеет уникальное местоположение
- Адреса соответствуют реальным местам в городе

### 👥 Участники:

- Некоторые задачи уже имеют участников
- Разные статусы: принятые, ожидающие, отклоненные

## После инициализации:

1. **Перейдите в раздел "Задачи"** - вы увидите добавленные задачи
2. **Проверьте карту** - задачи отобразятся как маркеры
3. **Тестируйте функционал** - принимайте задачи, создавайте новые

## Устранение проблем:

### Ошибка "Геолокация не поддерживается"

- Используйте ручной ввод координат
- Координаты по умолчанию: Москва (55.7558, 37.6176)

### Ошибка "Доступ к геолокации запрещен"

- Разрешите доступ к местоположению в браузере
- Или используйте ручной ввод координат

### Задачи не отображаются

- Проверьте, что вы находитесь в радиусе 1км от координат
- Обновите страницу
- Проверьте консоль браузера на ошибки

## Безопасность:

- Инструменты разработчика доступны только в режиме разработки
- В продакшене эта секция будет скрыта
- Тестовые данные не влияют на реальную работу приложения
